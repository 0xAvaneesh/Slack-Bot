Weather Bot

A simple Slack bot that tells you the real time weather for any city.

## How to Use It
1. Invite the bot to your Slack channel.
2. Type `/weather [city]` (for example: `/weather Tokyo` or `/weather Dubai`).
3. Get the current weather conditions sent right back to the chat.


-
## Features
* **Quick Queries:** Just hit `/weather` and a city name to get instant results.
* **Global Support:** Works for pretty much any city worldwide.
* **Clean Output:** Simple, easy-to-read messages so it doesn't clutter up your channel.
