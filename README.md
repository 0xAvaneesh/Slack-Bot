# Weather Bot

A simple Slack bot built for Hack Club Stardance that gives you live weather updates and forecasts for any location right inside Slack!

---

## What is this about?

This project started as a Slack bot to experiment with backend development, working with external APIs, and integrating services with Slack's Bolt SDK. Instead of leaving chat to check the weather, you can just run a quick slash command in any channel or DM to get live conditions anywhere in the world.

---

## How does it work?

To use the bot in Slack:
1. Open Slack and head over to any channel where the bot is added or msg it directly.
2. Type `/weather` followed by the city you want to check.

Example usage:
* `/weather London`
* `/weather Tokyo`
* `/weather Dubai`
